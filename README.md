\## Description

\*\*nvlogs\*\* is a utility add-on for NVDA that automatically archives your daily log files. To ensure no diagnostic data is lost, it creates a dedicated folder in your "Documents" directory and backs up the NVDA log every time the application starts or restarts.



This is particularly useful for developers, power users, and technical support teams who need to keep a history of NVDA's performance or debug intermittent issues without manually saving the log before each session.



\## Key Features

\* \*\*Automated Archiving:\*\* Copies the current `nvda.log` to your Documents folder on every startup.

\* \*\*Smart Organization:\*\* Creates a folder named `nvlogs\_logs\_nvda` for easy access.

\* \*\*Timestamped Logs:\*\* Each log file is saved with a precise timestamp (`YYYY-MM-DD\_HH-MM-SS`) to prevent overwriting and allow easy chronological tracking.

\* \*\*Lightweight \& Silent:\*\* Runs efficiently in the background without interrupting the user experience.



\## Installation

1\. Download the latest `.nvda-addon` file from the \[Releases](../../releases) section.

2\. Open the file to install it in NVDA.

3\. Your logs will start appearing in `Documents/nvlogs\_logs\_nvda`.
